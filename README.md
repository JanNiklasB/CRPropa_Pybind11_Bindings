# CRPropa Pybind11 Bindings Plugin

This plugin compiles crpropa with pybind11 bindings instead of swig bindings.
For that it clones a given git repository over fetch content and builts it from source, it is compatible with any CRPropa version.
It it not possible to use a preinstalled CRPropa since to be able to automatically built the binding files with binder we need the `compile_commands.json` and the `CMakeCache.txt` generated by CRPropa.

## Install requirements

### conda

```bash
conda install -c conda-forge compilers git cmake ninja zlib gperftools fftw hdf5 muparser python numpy pkgconfig pybind11
pip install cppbinder
```

## How to build CRPropa with this plugin

The building process is straight forward, clone the repository, install the requirements, specify the variables, build, install, done.

```bash
git clone https://github.com/JanNiklasB/CRPropa_Pybind11_Bindings.git
cd CRPropa_Pybind11_Bindings

mkdir build && cd build
cmake .. -G Ninja -D CMAKE_INSTALL_PREFIX=/path/to/your/desired/install/location
# by default the current master is pulled per fetch content, but you are also able to specify your own repo and tag or local CRPropa source
cmake --build .
# installing overwrites the existing crpropa!
cmake --install .
```
